# RootCode-AI

**Building tools for AI development.**

We design and build tooling, agents, and infrastructure that make it easier to develop with AI — from developer-facing SDKs to the plumbing that connects models to real-world workflows.

---

### 🚀 What we're building

**VoiceLK** — an AI-powered Sinhala text-to-speech learning platform for O/Level ICT students, split across three services:

- [`voicelk_fe`](https://github.com/RootCode-AI/voicelk_fe) — React + Vite frontend: chat-style topic input, history, profile, and help centre
- [`voicelk_be`](https://github.com/RootCode-AI/voicelk_be) — Spring Boot backend: auth, database, Gemini AI orchestration, and audio storage via Supabase
- [`adaptive-sinhala-tts`](https://github.com/RootCode-AI/adaptive-sinhala-tts) (`voicelk_ml`) — Python/Flask NLP microservice: code-switched Sinhala-English text normalisation and grapheme-to-phoneme conversion, with a VITS acoustic model in research
